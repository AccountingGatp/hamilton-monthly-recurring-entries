Recurring entries SOP

  1. Prepare three Excel exports. Use the recurring entries schedule, GL account list, and the ResMan accrual-basis Journal Entry Register for all properties. The register should cover the review dates and the preceding calendar month.
  2. Select the review period. Upload each workbook and set the inclusive start and end dates. Keep Automatic by month unless you need a specific schedule tab. Enable the prior-month schedule option only when you intend to use it for a missing month.
  3. Run the review. Select Run review. Check the schedule tab and monthly coverage shown in the results.
  4. Investigate exceptions. Select Show exceptions only to focus on differences. Compare expected amounts with current and prior net activity, then use the journal IDs to trace entries in ResMan.
  5. Save and validate drafts. Select Download results ZIP. Draft lines require a full month, a register printed after month-end, and supporting prior journal activity. Verify draft lines before posting.
